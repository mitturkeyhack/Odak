# Odak

Instagram'da Reels'i gizleyen Android uygulaması.

- Alt çubuktaki Reels simgesini gizler, kalan simgeleri eşit aralıkla dizer
- Keşfet'ten ve DM'den açılan Reels'i engeller
- Kapatmayı zorlaştırma: korumayı gevşetmek için 30 saniye bekletir

Erişilebilirlik Hizmeti ile çalışır. Ekrandaki hiçbir şeyi kaydetmez, internet izni yoktur.

## İndir

[Odak.apk (son sürüm)](https://github.com/mitturkeyhack/Odak/releases/latest/download/Odak.apk)
